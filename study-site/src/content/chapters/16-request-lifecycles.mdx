## What travels through the stack, wire to disk

Following a request end to end, every piece you've met has a seat at the table:

1. **Uvicorn** accepts the TCP connection and hands the request to FastAPI.
2. **FastAPI** routes to a function by method + path (the router prefix plays its part).
3. **Pydantic** validates the body → possible <Pill tone="indigo">422</Pill>.
4. **Dependencies** resolve: `get_db` opens a session; the auth dependency parses the header → possibly <Pill tone="rose">401</Pill>; a role dependency may 403 before the body runs.
5. **The endpoint body** calls ownership helpers that may 403, and executes the guarded SQL.
6. **SQLAlchemy** commits; on `IntegrityError` the code rolls back and returns a clean 4xx without a 500.
7. FastAPI serializes the `response_model` back to JSON.

<Cite path="app/routers/bookings.py" lines="146–169" />

```python
@router.post("/{booking_id}/book", response_model=BookingResponse)
def book_slot(booking_id: int, db=Depends(get_db), current_user: User = Depends(require_customer)) -> Booking:
    booking = get_booking_or_404(booking_id, db)
    result = db.execute(
        update(Booking)
        .where(
            Booking.id == booking.id,
            Booking.status == BookingStatus.PENDING,
            Booking.customer_id.is_(None),
        )
        .values(customer_id=current_user.id, status=BookingStatus.CONFIRMED)
    )
    if result.rowcount == 0:
        raise HTTPException(status_code=409, detail="Slot is no longer available")
    db.commit()
    db.refresh(booking)
    return booking
```

Spot every layer? Path param → dependency (session + role) → 404 guard → atomic conditional UPDATE → rowcount verdict → commit/refresh/serialize. That ordering is the whole book, compressed into twenty lines.
